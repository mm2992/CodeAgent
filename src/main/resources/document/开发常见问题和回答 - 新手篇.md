# 开发常见问题与解决方案 · 新手篇


#### 问题 1：我安装了 Python/Java，但终端输入 `python` 提示“命令未找到”，怎么办？

**答**：  
这通常是**环境变量**未配置正确。
- Windows：检查安装时是否勾选“Add to PATH”，若未勾选，需手动将安装目录（如 `C:\Python3xx\` 和 `C:\Python3xx\Scripts\`）添加到系统 Path 变量中。
- macOS/Linux：检查 shell 配置文件（`.bashrc` 或 `.zshrc`）是否添加了 `export PATH="/usr/local/bin/python3:$PATH"`，并执行 `source` 生效。  
  验证方法：重新打开终端，输入 `where python`（Windows）或 `which python3`（Mac/Linux）看是否返回路径。

#### 问题 2：代码明明没写错，但运行时报 `IndentationError`（缩进错误）？

**答**：  
Python 强制使用缩进表示代码块。常见原因：
- 混用了 Tab 和空格（建议编辑器设置为“空格代替 Tab”，一般 4 个空格）。
- 同一代码块内缩进量不一致（例如第一行 4 空格，第二行 2 空格）。
- 在 `if`、`for`、`def` 等语句后忘记缩进。  
  解决：使用 IDE（如 VS Code、PyCharm）开启“显示空白字符”功能，统一替换所有 Tab 为空格。

#### 问题 3：数组下标越界（IndexError）总在运行时出现，如何提前避免？

**答**：  
越界是因为访问了不存在的索引（如长度为 5 的列表，却访问 `list[5]`）。预防方法：
- 循环时用 `range(len(list))` 或直接 `for item in list`，避免手动计算索引。
- 若必须用索引，先 `if index < len(list)` 判断。
- 使用 `try-except` 捕获异常，但更推荐“防御式编程”——永远假设输入长度可能变化。

#### 问题 4：Git 提交时老是提示“Please tell me who you are”，怎么配置？

**答**：  
这是 Git 未设置全局用户信息导致的。执行以下两条命令：
